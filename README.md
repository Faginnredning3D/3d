# fag-3d

3D-visninger av fast innredning fra Faginnredning AS, til gjennomgang med kunde.
Hver ordre ligger i egen mappe og serveres via GitHub Pages.

- `2026-087` — Testleilighet Fjøsangerveien (GMB Student)
- `2026-076-P3-D012-Garderobe` — Personlige garderobeskap D012, Marken 37 (LAB Entreprenør)
- [2026-076-P3-D023-Garderobe](https://faginnredning3d.github.io/3d/2026-076-P3-D023-Garderobe/) – Marken 37, 5 personlige garderobeskap D023 (REV A 16.10.2026)
- [2026-076-P3-D024-Garderobe](https://faginnredning3d.github.io/3d/2026-076-P3-D024-Garderobe/) – Marken 37, 7 personlige garderobeskap D024 (REV A 16.10.2026)
- [2026-076-P3-D027-Garderobe](https://faginnredning3d.github.io/3d/2026-076-P3-D027-Garderobe/) – Marken 37, 7 personlige garderobeskap D027 (REV A 16.10.2026)
- `2026-076-PLAN-2-C016-BOKHYLLE2` — Bokhylle 2 C016, Marken 37 (LAB Entreprenør)
- `2026-076-Forrom-P4-E013` — Servant forrom E013, Marken 37 (LAB Entreprenør)

Modellene eksporteres fra imos iX med **VR Link** (VRML + teksturmappe) og konverteres
til glTF før publisering. Konverteringsverktøyet ligger på fellesen under
`17 Claude\03 Verktøy\wrl2glb`.

Sidene er merket `noindex` — de skal nås av den som får lenken, ikke via søkemotor.
